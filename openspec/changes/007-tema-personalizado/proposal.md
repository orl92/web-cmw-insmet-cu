# 078 — tema-personalizado

## Motivación

El sitio usa la paleta default de Tabler (azul primario #066fd1). Un centro meteorológico puede beneficiarse de una identidad visual propia con azules oceánicos y verdes costeros.

## Alcance

- Definir paleta CSS personalizada (CSS variables `--tblr-*`)
- Ajustar logo, favicon y colores de marca
- Crear tema "oscuro" personalizado (no solo `.dark` de Tabler)
- Aplicar a todos los components (botones, badges, cards, navbar)

## Criterios de Aceptación

1. Paleta personalizada aplicada globalmente
2. Dark mode usa colores adaptados (no solo inversión default)
3. Logo y favicon del CMP Camagüey
4. Sin regresiones visuales en componentes Tabler
